# 三幕音景 · Three Soundscapes

三段原创音乐，全部由 **Web Audio API** 在浏览器里实时合成。没有采样、没有音源库、没有第三方依赖，也没有加载任何图片或音频文件。

- **I. 晨露与麦浪 / Morning Fields** — 悠闲 · 乡村
- **II. 萤火秘境 / Lanterns of Elfhame** — 精灵 · 异世界
- **III. 霓虹矢量 / Neon Vector** — 现代 · 科幻

## 播放

直接双击 `index.html` 即可。页面不需要构建，也不需要联网。

如果浏览器对 `file://` 下的脚本有限制：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

### 操作

- 点击舞台中的 `I / II / III` 标签，或下方卡片，切换并播放乐章
- 空格：播放 / 暂停
- `1` / `2` / `3`：切换乐章
- `Esc`：关闭弹窗 / 停止
- **连续播放**：按顺序播放三个乐章
- **导出 WAV**：用 `OfflineAudioContext` 离线渲染当前乐章并下载
- 音量滑杆会实时作用于当前播放实例

## 三个乐章

| # | 标题 | 调性 / 拍号 / 速度 | 时长 | 配器 |
|---|------|---------------------|------|------|
| I | 晨露与麦浪 | D 大调 · 6/8 · 112 BPM | 0:48 | 木吉他、长笛、低音提琴、弦乐铺底、沙锤、铃鼓、鸟鸣 |
| II | 萤火秘境 | E 小调 · 4/4 · 84 BPM | 1:12 | 竖琴、FM 钢片琴、共振峰合唱、持续低音、框鼓、风、微光钟声 |
| III | 霓虹矢量 | A 小调 · 4/4 · 124 BPM | 1:00 | 16 分音符琶音、锯齿波铺底、Sub Bass、四拍底鼓、Clap、FM 主音、上升音效 |

完整连播约 **3:07**。

### I. 晨露与麦浪

6/8 的摇曳感来自“低音—五度—高音—三度”的指弹型。A 段长笛奏出五声音阶气质的主题，B 段加入沙锤、铃鼓、低音提琴与弦乐，A' 段由吉他低八度影子声部加厚。和声在 D–G–Bm–A 之间循环，结尾回到 D 大调主和弦，让混响自然收尾。

### II. 萤火秘境

竖琴以连续的 8 分音符铺开，钢片琴主题在高音区漂浮。合唱声部用三个共振峰带通滤波器塑形，唱的是没有词的元音。和声有意使用 `Cmaj7`、`Dsus2`、`G/B` 与 Dorian 色彩的 F#，避免强烈的属功能解决，让音乐保持“悬浮”。低音 E/B 持续音贯穿全曲。

### III. 霓虹矢量

124 BPM、四拍底鼓、16 分音符琶音与 sidechain 抽吸构成主律动。A 段主音在 Am–F–C–G 上展开，B 段整体升高音区并加入高频钟声。中段 break 抽掉鼓组，只留下铺底、琶音与 FM 钟声，再用 riser 推回第二次 drop。

## 技术实现

页面和三个 JS 文件：

```
index.html        页面、样式、Canvas 舞台
js/audio.js       合成引擎、效果链、调度器、离线渲染
js/score.js       乐谱构建器 + 三个乐章的音符/自动化
js/app.js         播放控制、进度、Canvas 视觉、WAV 导出
```

### 声音

- **加法拨弦**：预先在 22.05 kHz 下渲染每个音高的吉他/竖琴音色 —— 非谐分音、逐分音衰减、拨片噪声、琴体共振。播放时用 `AudioBufferSourceNode`，音高由缓冲本身决定，避免 Web Audio 反馈延迟导致的音准问题。
- **FM 钟声**：正弦载波 + 正弦调制器，调制指数随时间指数衰减；钢片琴与高频微光共用这套音色。
- **共振峰合唱**：两路失谐锯齿波并联三个带通滤波器（约 720 / 1180 / 2700 Hz），做出“啊/呜”的元音感。
- **铺底**：失谐振荡器 + 低通 + 慢速包络；乡村乐章使用三角波/正弦的暖色组合。
- **电子鼓**：正弦扫频底鼓、带通噪声军鼓/拍手、高通噪声镲片、滤波噪声沙锤。
- **效果**：程序化生成的立体声卷积混响（每个乐章不同衰减与阻尼）、乒乓延迟、声像、总线压缩与限制器。

### 调度

实时播放采用 lookahead 调度：每 140 ms 检查一次，把未来 1.6 秒内的事件排进 AudioContext。暂停使用 `AudioContext.suspend()`，恢复后时间线与已排事件原样继续。

### 导出

`OfflineAudioContext` 以 44.1 kHz / 立体声 / 16-bit PCM 渲染，渲染长度包含乐谱尾音。导出的 WAV 与在线播放使用同一套 Session、同一套效果链。

## 浏览器

需要支持 `AudioContext`、`StereoPannerNode`、`ConvolverNode` 与 `OfflineAudioContext` 的现代浏览器：

- Chrome / Edge 90+
- Safari 16+（iOS 首次播放需要点击）
- Firefox 90+

移动端为单列布局；舞台标签会收成 `I / II / III`。
