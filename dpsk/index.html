About this piece

没有采样，只有声音的积木

这三段音乐全部由 Web Audio API 实时合成：加法合成的拨弦、FM 钟声、共振峰人声、滤波锯齿波、程序化卷积混响，以及一颗一颗搭起来的电子鼓。页面上没有加载任何音频文件。

每段音乐都有自己的速度、调性、配器与效果链。切换乐章时，整个声音空间也会跟着换色。
